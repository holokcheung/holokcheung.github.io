Tactile and audio maps for blind and visually impaired people

Scan a room with a LiDAR iPhone and TouchSpace turns it into a floor plan and walkable navigation graph that rises as pins on a 2,400-pin Dot Pad tactile display. Ask a question out loud and Claude works out what you mean; the answer comes from the real map data and Dijkstra route planning computes every path, so the AI can never make one up. A FastAPI backend with 20 endpoints and 153 automated tests powers the React web app. Built with James Zheng and Sunghyuk Yoon.

My part: the FastAPI backend, the React web app, the map schema and floor-plan processing, RoomPlan import, Dijkstra routing, the Claude question interpreter, the route editor, and the 60×40 Dot Pad preview. James built the Bluetooth Dot Pad driver. On AI: Claude only interprets the question; every answer and route comes from deterministic map functions, and the 153 tests cover all 20 endpoints.

An AI pronunciation trainer for English learners

naccent transcribes your speech with the OpenAI Whisper API and scores it sound by sound through SpeechAce and a Flask service, so you can see how each sound compares with a native speaker. The Next.js frontend tracks your progress over time.

My part: I built the Whisper transcription and SpeechAce scoring pipeline behind the Flask service and shipped the Next.js frontend with Chart.js progress charts, after replacing a first version that scored with an LLM alone and handled accents and phonetic detail poorly.
